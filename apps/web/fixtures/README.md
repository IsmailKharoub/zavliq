# Public integration fixtures

`hello.txt` contains demonstration text for explicit cross-client file transfers.

`recovery-interoperability.age` is a synthetic public crypto fixture, generated by the browser's established [age implementation](https://github.com/FiloSottile/typage) and Matrix Rust WASM implementation. It contains no real account or production data. Its public passphrase is `public interoperability fixture password`; its fake enrollment proof is 64 `f` characters, handle `fixture`, and one generated room session for `!interop:localhost`. The native Rust test decrypts it independently and validates Matrix room-key interoperability. Regenerate deliberately with `ZAVLIQ_WRITE_INTEROP_FIXTURE=1 pnpm --filter @zavliq/web test`.
